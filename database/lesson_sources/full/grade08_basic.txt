# Context Clues | Using nearby words to understand unfamiliar words.
> You do not always need a dictionary. The words around an unfamiliar word can give you hints.
= Context clues :: hints in a sentence that help explain the meaning of a word.
= Definition clue :: the meaning is given directly.
= Synonym clue :: a word with a similar meaning is nearby.
= Antonym clue :: a word with the opposite meaning is nearby.
= Example clue :: examples show the meaning.
! Example :: "The house was immaculate, so clean that not a speck of dust could be found." The phrase "so clean" tells us immaculate means very clean.
? What are context clues? :: Hints in a sentence that help explain a word's meaning.
? In "He was timid, not brave like his brother," what does timid mean? :: Shy or not brave (antonym clue)
? What type of clue gives the meaning directly? :: Definition clue

@ HS8-MATH
# Factoring Polynomials | Writing a polynomial as a product of simpler factors.
> Factoring is the reverse of multiplying. It breaks an expression into parts that multiply to give it.
= Polynomial :: an expression with one or more terms, like x² + 5x + 6.
= Factor :: an expression that divides another evenly.
= Greatest common factor (GCF) :: the largest factor shared by all terms.
= Difference of two squares :: a² − b² = (a + b)(a − b).
! Example :: GCF: 6x + 9 = 3(2x + 3). Difference of squares: x² − 25 = (x + 5)(x − 5). Trinomial: x² + 5x + 6 = (x + 2)(x + 3), because 2 × 3 = 6 and 2 + 3 = 5.
? Factor 4x + 12. :: 4(x + 3)
? Factor x² − 16. :: (x + 4)(x − 4)
? Factor x² + 7x + 10. :: (x + 2)(x + 5)

# Rational Algebraic Expressions | Fractions with polynomials, and how to simplify them.
> Just like fractions with numbers, we can have fractions with variables.
= Rational algebraic expression :: a fraction whose numerator and denominator are polynomials.
= Simplest form :: when the numerator and denominator have no common factor.
= Restriction :: a value that makes the denominator zero, which is not allowed.
* To simplify, factor the numerator and denominator, then cancel common factors.
! Example :: (x² − 9) / (x + 3) = (x + 3)(x − 3) / (x + 3) = x − 3, where x ≠ −3.
? What is a rational algebraic expression? :: A fraction whose numerator and denominator are polynomials.
? Simplify (2x + 4) / 2. :: x + 2
? Why can't the denominator be zero? :: Division by zero is undefined.

@ HS8-SCI
# Forces and Newton's Laws | How forces change the motion of objects.
> Every push or pull you make is a force. Newton's three laws explain how forces affect motion.
= Force :: a push or pull, measured in newtons (N).
= Inertia :: the tendency of an object to resist change in its motion.
= First law :: an object stays at rest or in motion unless a force acts on it.
= Second law :: force = mass × acceleration (F = ma).
= Third law :: for every action, there is an equal and opposite reaction.
! Example :: Passengers lurch forward when a jeepney stops suddenly (first law). A rocket pushes gas down, and the gas pushes the rocket up (third law).
? What is inertia? :: The tendency of an object to resist change in motion.
? What is the formula of the second law? :: F = ma
? Which law explains a rocket launch? :: Third law

# Work, Power, and Energy | How force moves objects and how energy changes form.
> When you lift your bag, you do work and use energy. These ideas are connected.
= Work :: done when a force moves an object; work = force × distance, measured in joules (J).
= Energy :: the ability to do work.
= Kinetic energy :: energy of a moving object.
= Potential energy :: stored energy, such as an object held high.
= Power :: how fast work is done; power = work ÷ time, measured in watts (W).
! Example :: Lifting a 20 N box up 2 m does 20 × 2 = 40 J of work. If it takes 4 seconds, power = 40 ÷ 4 = 10 W.
? What is energy? :: The ability to do work.
? A ball rolling down a hill has what kind of energy? :: Kinetic energy
? Pushing with 10 N for 3 m does how much work? :: 30 J
